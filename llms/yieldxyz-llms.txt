## API Reference
- [Authentication](https://docs.yield.xyz/reference/authentication.md)
- [List all yield opportunities](https://docs.yield.xyz/reference/yieldscontroller_getyields.md): Retrieve a paginated list of available yield opportunities across all supported networks and protocols.
- [Get yield metadata](https://docs.yield.xyz/reference/yieldscontroller_getyield.md): Retrieve detailed information about a specific yield opportunity including APY, tokens, protocol details, and more.
- [Get yield validators](https://docs.yield.xyz/reference/yieldscontroller_getyieldvalidators.md): Retrieve a paginated list of validators available for staking or delegation for this yield opportunity.
- [List enabled networks](https://docs.yield.xyz/reference/networkscontroller_getnetworks.md): Retrieve networks with enabled yield opportunities for the authenticated project.
- [Get all providers](https://docs.yield.xyz/reference/providerscontroller_getproviders.md): Returns a paginated list of all providers, including both protocol and validator providers.
- [Get provider by ID](https://docs.yield.xyz/reference/providerscontroller_getprovider.md): Returns detailed information about a specific provider.
- [Get yield campaigns](https://docs.yield.xyz/reference/yieldscontroller_getyieldcampaigns.md): Returns campaign metadata for the given yield opportunity within the API key project scope.
- [List tokens with available yields](https://docs.yield.xyz/reference/tokenscontroller_gettokens.md): Retrieve tokens that have at least one enabled yield available for this project. Optionally filter by one or more networks and yield types. Returns the full list by default; callers should respect `total` and use `offset`/`limit`, as a default page size may be introduced in future.
- [Get balances across multiple yields and networks](https://docs.yield.xyz/reference/yieldscontroller_getaggregatebalances.md): Retrieve balances for multiple wallet addresses across different networks and yield opportunities. Send an array of balance requests - each request can specify a yieldId (optional for chain scanning), address, network, and custom arguments. This is the same format as the single yield balance endpoint but in array form. Duplicate requests (same yieldId + address + network) are automatically deduplicated, with specific yield requests taking precedence over chain scans.
- [Get balances for a specific yield](https://docs.yield.xyz/reference/yieldscontroller_getyieldbalances.md): Retrieve all balances associated with a yield opportunity for a specific wallet address, including active, pending, claimable, and withdrawable balances. The network is automatically determined from the yield configuration.
- [Get historical balance snapshots for a yield](https://docs.yield.xyz/reference/yieldscontroller_getbalancehistory.md): Returns a chronological time series of balance snapshots for a wallet address within a yield. Each entry reflects the position at a specific timestamp or block. Supports configurable sampling intervals and point-in-time queries. Only available for ERC4626 vaults with indexed transfer history.
- [Get reward history](https://docs.yield.xyz/reference/yieldscontroller_getyieldrewards.md): Retrieve a chronological list of on-chain reward events for an indexed yield. Each record includes timestamp, token metadata, amount, reward source, and transaction reference.
- [Get user actions](https://docs.yield.xyz/reference/actionscontroller_getactions.md): Retrieve all actions performed by a user, with optional filtering by yield, status, category, etc. In the future, this may include personalized action recommendations.
- [Get action details](https://docs.yield.xyz/reference/actionscontroller_getaction.md): Retrieve detailed information about a specific action including current status, transactions, and execution details.
- [Enter a yield](https://docs.yield.xyz/reference/actionscontroller_enteryield.md): Generate the transactions needed to enter a yield position with the provided parameters.
- [Exit a yield](https://docs.yield.xyz/reference/actionscontroller_exityield.md): Generate the transactions needed to exit a yield position with the provided parameters.
- [Manage a yield](https://docs.yield.xyz/reference/actionscontroller_manageyield.md): Generate the transactions needed to perform management actions on a yield position.
- [Submit transaction hash](https://docs.yield.xyz/reference/transactionscontroller_submittransactionhash.md): Submit the transaction hash after broadcasting a transaction to the blockchain. This updates the transaction status and enables tracking.
- [Submit transaction](https://docs.yield.xyz/reference/transactionscontroller_submittransaction.md): Submit the transaction to the blockchain.
- [Get transaction details](https://docs.yield.xyz/reference/transactionscontroller_gettransaction.md): Retrieve detailed information about a specific transaction including current status, hash, and execution details.
- [Get risk ratings for a yield](https://docs.yield.xyz/reference/yieldscontroller_getyieldrisk.md): Retrieve consolidated risk ratings from third-party providers for a yield.
- [Get historical reward rate snapshots for a yield](https://docs.yield.xyz/reference/yieldscontroller_getyieldrewardratehistory.md): Returns a chronological time series of reward rate snapshots for the specified yield, suitable for charting and analytics. Supports configurable time ranges, sampling intervals (day/week/month), and pagination.
- [Get historical TVL snapshots for a yield](https://docs.yield.xyz/reference/yieldscontroller_getyieldtvlhistory.md): Returns a chronological time series of Total Value Locked for the specified yield, expressed in underlying token units. Supports configurable time ranges, sampling intervals (day/week/month), and pagination.
- [Get the KYC status of an address for a yield](https://docs.yield.xyz/reference/kyccontroller_getstatus.md): Returns the normalized KYC status for the given address. Yields without a KYC requirement return not_required.
- [Health check](https://docs.yield.xyz/reference/healthcontroller_health.md): Get the health status of the yield API with current timestamp
- [List all providers](https://docs.yield.xyz/reference/providerscontroller_getproviders-1.md): Retrieve a list of available perps trading providers with their supported actions and argument schemas.
- [Get provider details](https://docs.yield.xyz/reference/providerscontroller_getprovider-1.md): Retrieve detailed information about a specific perps trading provider
- [List all markets](https://docs.yield.xyz/reference/marketscontroller_getmarkets.md): Retrieve a paginated list of available perps markets across all supported providers and instruments.
- [Get market by ID](https://docs.yield.xyz/reference/marketscontroller_getmarketbyid.md): Retrieve a single market by its ID, including chart display configuration.
- [Get historical candles](https://docs.yield.xyz/reference/marketscontroller_getcandles.md): Retrieve historical OHLCV candle data for a market. Limited to 5000 candles per request.
- [Execute an action](https://docs.yield.xyz/reference/actionscontroller_executeaction.md): Generate unsigned transactions for a trading action (open/close positions, manage leverage, set stop loss/take profit, fund/withdraw). Returns transaction data ready to be signed by the user.
- [Submit transaction](https://docs.yield.xyz/reference/transactionscontroller_submittransaction-1.md): Submit a signed transaction to the blockchain or protocol, or record a transaction hash if already submitted. Provide either signedPayload (to have us broadcast) or transactionHash (if already submitted). The transaction must have been created via the actions endpoint.
- [Get action by ID](https://docs.yield.xyz/reference/actionscontroller_getaction-1.md): Retrieve detailed information about a specific action including current status, transactions, and execution details.
- [Get user actions](https://docs.yield.xyz/reference/actionscontroller_getactions-1.md): Retrieve all actions performed by a user on a specific provider, with optional filtering by status and action type. Returns a paginated list ordered by most recent first.
- [Get perp events](https://docs.yield.xyz/reference/eventscontroller_getevents.md): Retrieve async venue outcomes (fills, liquidations, SL/TP triggers) for a user on a specific provider. Returns a paginated list ordered by most recent first.
- [Get event by ID](https://docs.yield.xyz/reference/eventscontroller_getevent.md): Retrieve a single perp event by its UUID.
- [Get unified perp activity](https://docs.yield.xyz/reference/activitycontroller_getactivity.md): Paginated chronological feed of timeline events and user actions for an address on one or more providers (newest first). Pass providerId or providerIds. Events use occurredAt; actions use createdAt.
- [Get positions](https://docs.yield.xyz/reference/portfoliocontroller_getpositions.md): Retrieve active positions for a wallet address. Pass providerId or providerIds (one or more providers).
- [Get orders](https://docs.yield.xyz/reference/portfoliocontroller_getorders.md): Retrieve open orders for a wallet address. Pass providerId or providerIds (one or more providers).
- [Get account balance](https://docs.yield.xyz/reference/portfoliocontroller_getbalances.md): Retrieve account balance and margin for one provider. Use providerId or providerIds with exactly one provider (not multiple).
- [Health check](https://docs.yield.xyz/reference/healthcontroller_health-1.md): Get the health status of the perps API with current timestamp
- [Get user positions](https://docs.yield.xyz/reference/positionscontroller_getpositions_v1.md): Retrieve all supply and borrow positions for a user address across specified integration and network.
- [Get user liquidation history](https://docs.yield.xyz/reference/positionscontroller_getliquidations_v1.md): Retrieve a paginated history of Morpho Blue liquidation events for a borrower address, read from the indexed store. This is the only place a fully-liquidated (closed) position can be retrieved, since it no longer appears in GET /v1/positions. Ordered by most recent first.
- [List actions](https://docs.yield.xyz/reference/actionscontroller_getactions_v1.md): Get a paginated list of actions, with optional filtering by address, integration, status, etc.
- [Execute a borrow action](https://docs.yield.xyz/reference/actionscontroller_executeaction_v1.md): Generate unsigned transactions for a lending/borrowing action. Returns transaction(s) to sign. Submit each signed transaction via POST /transactions/:id/submit. For async multi-step flows (e.g., cross-chain bridges), hasNextStep will be true — call POST /actions/:id/step after confirmation to get the next transaction(s).
- [Get action by ID](https://docs.yield.xyz/reference/actionscontroller_getaction_v1.md): Retrieve detailed information about a specific action including current status, transactions, and step progress.
- [Get next step transaction(s)](https://docs.yield.xyz/reference/actionscontroller_step_v1.md): For async multi-step actions (e.g., cross-chain bridges, delayed withdrawals), retrieve the next transaction(s) after the previous step has been confirmed on-chain. Call this when hasNextStep is true on the action response.
- [Submit signed transaction](https://docs.yield.xyz/reference/transactionscontroller_submittransaction_v1.md): Submit a signed transaction. Provide signedPayload to have us broadcast it to the blockchain, or transactionHash if already submitted by the client.
- [List all integrations](https://docs.yield.xyz/reference/integrationscontroller_getintegrations_v1.md): Retrieve a list of available lending/borrowing integrations (e.g., Aave, Spark, Morpho) with their supported actions and networks.
- [Get integration details](https://docs.yield.xyz/reference/integrationscontroller_getintegration_v1.md): Retrieve detailed information about a specific lending/borrowing integration
- [List all lending markets](https://docs.yield.xyz/reference/marketscontroller_getmarkets_v1.md): Retrieve a paginated list of available lending markets across all supported integrations and networks. Each market represents a token that can be supplied or borrowed.
- [Get a single market by ID](https://docs.yield.xyz/reference/marketscontroller_getmarketbyid_v1.md): Retrieve details for a specific lending market. Useful for deep linking into a specific market (e.g., cbBTC/USDT on Morpho Blue).
- [Health check](https://docs.yield.xyz/reference/healthcontroller_health-2.md): Get the health status of the borrow API with current timestamp
